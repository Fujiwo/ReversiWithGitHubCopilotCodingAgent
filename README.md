# ReversiWithGitHubCopilotCodingAgent

このリポジトリは、クラシックなボードゲーム「リバーシ（オセロ）」をモダンなJavaScriptで実装したプロジェクトです。  
AI対戦（難易度選択可）、アンドゥ機能、キーボード操作、アクセシビリティ対応など、実用的な機能を備えています。  
コードは可読性・拡張性を重視しており、学習やカスタマイズにも適しています。

主な特徴:
- 8x8標準リバーシ盤
- プレイヤー対AI（難易度3段階）
- アンドゥ（1手戻し）機能
- キーボード操作・アクセシビリティ対応
- 状態管理とUIの分離設計

ご自由にご利用・改変ください。
